## Building

**SEED**: a control layer for AI agents near production. In the demo, an agent investigates a failure read-only, stops at a human approval gate before any change, applies a bounded fix, and leaves a receipt for every step. *Private; demo on request.*

**Architect**: an AI system for technical task execution under strict human control. Actions are gated and recorded, and capabilities are tested before they are promoted. *Private; [docs](https://www.plainchaos.me/projects/architect).*
